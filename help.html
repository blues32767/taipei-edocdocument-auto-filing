一

下載與安裝

請從官方商店安裝，會自動更新。

瀏覽器安裝位置
Google ChromeChrome 線上應用程式商店（搜尋「臺北市公文自動存查助手」）
Microsoft EdgeMicrosoft Edge 增益集
安裝後，到公文頁按 F5 重新整理，右下角會出現「公文意見助手」。之後更新會由商店自動完成。

名稱說明：商店上的名稱為既有上架名稱，功能已整合為「公文助手」（自動存查、登入自動化、AI 擬辦）。

二

選擇 AI 路線

三條路線擇一即可，不需全部完成。完成後直接跳到「疑難排解」。

路線適合對象公文去向
A　本地模型＋LM Studio（推薦）大多數使用者；有一台能跑模型的電腦留在本機
B　網路 API（Google Gemini）電腦較舊、無法跑本地模型送到 Google，需確認機關規定
C　其他本地服務（Ollama、手動 PORT）進階使用者，或已在用 Ollama留在本機

路線 A｜本地模型＋LM Studio（推薦）

完成後，設定頁應顯示「已解析成功」與「連線成功」。

A-1
安裝 LM Studio（lmstudio.ai）。LM Studio 是在個人電腦上下載、管理與執行大型語言模型的桌面應用程式。
A-2
安裝後啟動 LM Studio，點左側最下方的 Model Search（Ctrl+Shift+M），搜尋 gemma4 e4b 並按 Download。
電腦較舊請選 e2b；有獨立顯卡可選較大的模型。
A-3
點左側第二個圖示 Developer（Ctrl+2），按右側 + Load Model 載入剛下載的模型；再把左側的 Status 開關切換為 Running（Ctrl+.）。
A-4
點下方已載入模型旁的 </> cURL 按鈕，複製整段設定值。
A-5
回到「公文意見助手 · 選項」頁，於 01 AI 連線方式（預設即為 cURL 指令）貼上，按 儲存設定；網址、埠號與模型 ID 會自動帶入。再按 測試 AI 連線，出現「連線成功，回覆：連線成功」即完成。
完成路線 A 後，不需要再設定 Google API、Ollama 或手動填寫 PORT。

路線 B｜網路 API（Google Gemini）

公文文字會傳送到 Google，使用前請確認機關規定允許。

B-1
以瀏覽器開啟 Google AI Studio（aistudio.google.com），用 Google 帳號登入。
B-2
按 Get API key → Create API key，建立後按 Copy。金鑰等同密碼，不要傳給他人或貼到截圖中。
B-3
回到設定頁 01 AI 連線方式，選 網路 API，模型 ID 填 gemini-flash-latest，API 金鑰貼上（前後不要有空白），按 儲存設定，再按 測試 AI 連線。
Google 的介面與免費額度可能調整，若畫面不同請以 AI Studio 現況為準。

常見錯誤

錯誤訊息可能原因處理方式
HTTP 401金鑰未填、填錯、多了空白，或已刪除重新複製金鑰貼上；金鑰外流時，到 AI Studio 刪除後重建
HTTP 403API 未啟用、金鑰有使用限制，或地區不支援到 AI Studio 確認金鑰可用，或改在另一個專案建立
HTTP 404模型 ID 錯誤改填 gemini-flash-latest
HTTP 429超過免費額度或每分鐘次數上限等幾分鐘再試

路線 C｜其他本地服務（進階）

適合已在使用 Ollama，或不想貼 cURL 的進階使用者。

C-1　Ollama（Windows／macOS）

1
到 ollama.com 下載並安裝，在終端機執行 ollama pull gemma3。
2
瀏覽器開啟 http://127.0.0.1:11434/v1/models，複製畫面上的 id。
3
設定頁 01 AI 連線方式 → 選 常用服務（進階） → 服務選 Ollama，PORT 為 11434，模型 ID 貼上 → 儲存 → 測試連線。
若出現 HTTP 403（forbidden origin），請設定環境變數 OLLAMA_ORIGINS 為 *，重新啟動 Ollama 後再測試。

C-2　LM Studio 手動填 PORT（不貼 cURL）

1
完成路線 A 的 A-1 至 A-3（載入模型並啟動 Running）。
2
瀏覽器開啟 http://127.0.0.1:1234/v1/models，複製 id（例如 google/gemma-3-4b）。
3
設定頁選 常用服務（進階） → 服務選 LM Studio，PORT 填 1234，模型 ID 貼上 → 儲存 → 測試連線。
若 cURL 欄位有內容，會優先使用 cURL。要改用手動 PORT，請先按「清空 cURL」再儲存。
三

面板快捷按鈕

公文頁右下角的面板，依用途分為兩組。可在面板的「快捷按鈕、提示詞與字數設定」中勾選要顯示的按鈕。

一般工具（不使用 AI）

按鈕功能注意事項
複製日期-文號-主旨從公文擷取「發文日期、發文字號、主旨」，組成一行檔名格式，例如 1151019-北市教專字第1156010644號-敦聘…請查照。，並複製到剪貼簿，方便重新命名檔案。缺少任一欄位時會提示「未辨識到：…」。
複製全文到剪貼簿將公文文字（已去除裝訂線、頁碼與斷行）複製到剪貼簿。若瀏覽器阻擋自動複製，會改開視窗，請按「複製全文」。
開啟純文字在獨立文字視窗中檢視公文，可直接編輯、刪除不需要的段落，再按「複製全文」或「下載 .txt」。誤刪可按「還原原文」。關閉前若有未複製的修改會先提醒。

AI 功能（需設定模型）

按鈕功能注意事項
AI 擬稿依提示詞產生擬辦草稿，並填入「我的意見」欄位。不會自動送出，請自行確認。若欄位已有文字，會詢問覆蓋或附加。
AI重點摘要依提示詞整理公文重點，於獨立視窗顯示，可下載或複製。僅供閱讀，不會寫入意見。
面板標題列的「—」可把面板縮成「助」圖示；三種狀態都可以拖曳移動，避免擋住公文內容。
四

疑難排解

依現象找原因。大多數問題都是「沒重新整理」或「PORT／模型不一致」。

公文頁右下角沒有出現「公文意見助手」面板
  1. 到 chrome://extensions 確認本擴充套件已啟用，再回公文頁按 F5。
  2. 網址開頭須為 https://edoc.gov.taipei/tcqb/oa/。
  3. 公文簽核小框（網址含 app=genpages）刻意不顯示面板。
貼上 cURL 後顯示「cURL 格式有誤」
  • 請整段複製，包含 -d '…' 單引號內的 JSON。
  • JSON 必須含 "model" 欄位。
  • 建議直接使用 LM Studio 的 cURL 按鈕複製，不要手動改寫換行。
無法連線（Failed to fetch、connection refused）
  • 確認 LM Studio 的 Status 為 Running，或 Ollama 已在執行。
  • 埠號要與伺服器一致（LM Studio 預設 1234；Ollama 預設 11434）。
  • 防火牆可能阻擋，請允許 LM Studio 或 Ollama 的連線。
HTTP 404、模型未載入、HTTP 400 或 500
  • 404：模型 ID 錯誤，請重新複製 cURL，或到 /v1/models 查詢。
  • 400／500：模型尚未 Load，載入後再測試。
顯示「尚未允許 https://… 的存取權限」

cURL 或自訂網址指向非本機網址時，Chrome 需要授權一次。請在設定頁按「儲存設定」，並在跳出的權限視窗按「允許」。

逾時

模型太大或記憶體不足。請換小模型，或在「處理參數」把逾時調到 120～180 秒後儲存。

設定儲存了，但面板行為沒有改變

設定需要重新整理公文頁才會生效，儲存後請按 F5。

五

隱私與回報問題

使用前請先確認機關規定。

  • 本地模型（路線 A、C）：公文只在你的電腦與本機伺服器之間傳遞。
  • 網路 API（路線 B）：公文文字會傳送到該服務商。
  • 送出前可勾選「遮蔽身分證字號、手機與 Email」（市話不會遮蔽）。
  • AI 產生的擬辦與重點僅供參考，送出前請承辦人自行確認。
回報問題時，到設定頁「除錯」按 匯出除錯紀錄，連同錯誤訊息一起提供。不要附上 API 金鑰或公文內容。
