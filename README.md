# 臺北市公文助手（非官方工具）

寫公文時，常要重複複製文號、把 Word 內容一段一段貼進「說明」、還要逐件存查。**臺北市公文助手**是一個安裝在瀏覽器裡的小工具，幫您把這些重複的事情變簡單。

> ⚠️ 這是民間開發的非官方工具，**不是臺北市政府的官方產品**。使用前請先確認您機關的資訊安全規定。

---

## 📥 下載與安裝

**最簡單的方式：從 Chrome 線上應用程式商店安裝**

👉 [前往安裝（Chrome 線上應用程式商店）](https://chromewebstore.google.com/detail/oiiaicbnnhogpfihckgkdnmbmclhalmg?utm_source=item-share-cb)

安裝步驟：
1. 點上面的連結。
2. 按下「新增至 Chrome」，再按「新增擴充功能」。
3. 安裝完成後，打開公文系統頁面，按 **F5** 重新整理一次。

適用瀏覽器：**Google Chrome**（建議 111 以上版本）或 **Microsoft Edge**。

> 如果商店無法安裝，請參考文末「進階：手動安裝」。

---

## ✨ 它可以幫您做什麼？

打開公文頁面後，右下角會出現「公文助手」面板，常用功能都在這裡。

| 功能 | 白話說明 | 需要 AI 嗎？ |
|---|---|---|
| **複製日期、文號與主旨** | 一按就組好「發文日期-文號-主旨」，方便取檔名 | 不需要 |
| **複製全文到剪貼簿** | 把整篇公文複製下來，貼到 Word 或信件就能用 | 不需要 |
| **開啟純文字** | 在獨立視窗閱讀、整理公文，還能刪段落、存成文字檔 | 不需要 |
| **寫入說明內容** | 從 Word 複製多段文字，一按就依段落寫進「說明」欄位 | 不需要 |
| **AI 擬稿**（選用） | 依您的提示產生擬辦草稿，填入「我的意見」 | 需要設定 |
| **AI 重點摘要**（選用） | 幫您快速抓出公文重點 | 需要設定 |
| **待結案公文自動存查** | 在「待結案」頁面，自動勾選同一檔號的公文並依序存查 | 不需要 |

### 📌 小提醒
- **不想用 AI 也完全沒問題**，複製、純文字、寫入說明與自動存查都不需要 AI。
- AI 產生的內容**只是草稿**，不會自動送出或核章，請您自己檢查後再使用。

## 🧭 第一次使用，照著做就好

1. **安裝**：依上方「下載與安裝」完成安裝。
2. **打開公文頁面**：進入公文系統，右下角會出現「公文助手」面板。
3. **複製或寫入內容**：
   - 要複製文號或主旨：直接按「複製日期-文號-主旨」。
   - 要把 Word 內容寫進說明：先在 Word 選取並複製，再按「寫入說明內容」。
4. **（選用）自動存查**：到擴充功能的設定頁，填好「檔號」與「案次號」並儲存，進入「待結案」頁面後按「開啟自動存查功能」。
   - 預設值為檔號 `03010101`、案次號 `1`，可依您的業務自行修改。
5. **（選用）AI 功能**：如果想用 AI 擬稿或摘要，請到設定頁依說明完成設定。

---

## ⚠️ 使用前請先看

- **自動存查只在「待結案」頁面使用**。請先把清單整理好，只留下同一檔號的公文，本工具不會替您判斷公文類別。
- **紙本文數量要自己填**：遇到需要填寫紙本文數量的公文，若自動作業停下來，請手動填寫後再繼續。
- **AI 的內容要自己檢查**，系統不會替您送出或核章。
- **共用電腦請勿開啟自動登入**：自動登入會使用卡片的 PinCode，請只在自己的電腦上使用。
- **目前尚未支援「解除列管」**，待後續版本更新。
- **使用結果由使用者自行負責**：擬辦內容、摘要、寫入的說明文字與存查結果，請您在送出前自行檢查，本工具不對上述結果的正確性、完整性或適法性作出保證。
- **雲端 AI 會接收您送出的文字**。若公文內容涉及機密或個資，請使用本機 AI 或不使用 AI 功能，並遵守機關規定。

---

## 🔒 您的資料去哪裡？

- 所有設定都**儲存在您自己的瀏覽器裡**，本工具不會收集或上傳您的資料。
- 只有在您主動使用 **AI 功能**時，文字才會送到您設定的 AI 服務：
  - 使用**本機 AI**（例如 LM Studio、Ollama）：文字只在您自己的電腦上處理。
  - 使用**雲端 AI**（例如 Google Gemini）：文字會傳送到該服務商。
- 可在設定中開啟「遮蔽身分證字號、手機與 Email」，送出前先遮掉這些資料。

## 🙋 常見問題

**Q：按了按鈕沒有反應？**
A：先按 F5 重新整理公文頁面再試一次；仍不行，請確認您目前所在的頁面是否正確。

**Q：檔號和案次號要在哪裡改？**
A：點瀏覽器右上角的擴充功能圖示，進入設定頁修改後按儲存即可。

**Q：不會用 AI，可以只用基本功能嗎？**
A：可以，完全不需要設定 AI。

**Q：在學校教學或機關內部使用，算不算商用？**
A：不算。本授權明確允許學校、教育機構、政府機關與公益團體的非營利使用。教師在班級示範、機關同仁在內部公務上使用，都屬於非商業用途。

**Q：委外廠商（例如幫機關維護系統的公司）可以使用嗎？**
A：授權條款並未明確規定委外情形，屬於需要確認的範圍。建議先與作者聯繫（見文末），或請機關法務人員確認後再使用。

**Q：收費的教育訓練或講座，可以介紹本工具嗎？**
A：單純說明使用方法、不以本工具營利，通常不屬於商業用途；但若收費的目的是販售本工具或附帶銷售服務，就可能屬於商業用途。仍建議先與作者確認。

**Q：發現問題或想提建議，要去哪裡？**
A：可以到 GitHub 的 Issue 留言。回報時請先移除公文文號、人名、電話等個人資料；若是安全問題，請不要公開貼出細節，請依 [SECURITY.md](SECURITY.md) 的方式回報。

## 🛠️ 進階：手動安裝（開發者用）

適用於商店無法安裝、或想自行修改程式的使用者。

1. 下載本專案並解壓縮。
2. 在網址列輸入 `chrome://extensions`（Edge 請輸入 `edge://extensions`）。
3. 開啟右上角「開發人員模式」。
4. 點「載入未封裝項目」，選擇解壓縮後的資料夾。
