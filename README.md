# 臺北市公文系統助手（非官方）

協助臺北市公文系統使用者製作公文的 Chrome / Edge 擴充套件，提供日期-文號-主旨複製、純文字檢視、Word 段落自動分行寫入「說明」欄位、AI 擬辦與重點摘要（可選）、登入頁自動登入（可選）等功能。

> **非官方工具**：本專案與臺北市政府或公文系統主管機關無隸屬關係，也不保證與未來版本的公文系統相容。

---

## 主要功能

| 功能 | 說明 |
|---|---|
| 複製日期-文號-主旨 | 組合檔名並複製到剪貼簿 |
| 複製全文到剪貼簿 | 將公文文字複製到剪貼簿 |
| 開啟純文字 | 另開視窗，可刪段、編輯、下載或複製 |
| 寫入說明內容 | 貼上 Word 段落，依段落自動分行寫入「說明」欄位（見下方） |
| AI 擬稿／AI 重點摘要 | 可選功能，需自行設定本地或雲端 AI 服務 |
| 自動存查、自動登入 | 可選功能，詳見 `help.html` |

### 貼上段落（寫入說明內容）

1. 在 Word 中選取多段文字並複製。
2. 在公文頁面按下「寫入說明內容」，或在說明欄位按右鍵選「貼上段落」。
3. 系統會清除項目符號與編號（如 `一、`、`(一)`、`1.`），再逐行寫入「說明」欄位。

**注意事項**
- 游標若不在「說明」段落，系統會嘗試自動移到說明段落。
- 寫入過程若出現錯誤，會停止並列出尚未寫入的內容，請手動處理。
- 如遇異常，可於瀏覽器的開發者工具 Console 執行以下指令暫時停用此功能；恢復時執行 `localStorage.removeItem('edocPasteSplitOff')`：

```javascript
localStorage.setItem('edocPasteSplitOff', '1');
```

## 安裝（開發者模式）

1. 下載或 clone 本專案。
2. 開啟 `chrome://extensions`（Edge 請開啟 `edge://extensions`）。
3. 開啟右上角「開發人員模式」。
4. 點選「載入未封裝項目」，選擇本資料夾。

> 最低支援版本：Chrome 111 以上。

## 權限說明

| 權限／網域 | 用途 | 是否必要 |
|---|---|---|
| `storage` | 於本機瀏覽器儲存設定 | 必要 |
| `edoc.gov.taipei/tcqb/oa/*` | 僅在公文製作頁面注入功能 | 必要 |
| `127.0.0.1`、`localhost` | 連線本機 AI 服務（LM Studio、Ollama） | 可選 |
| `generativelanguage.googleapis.com` | 使用者選擇 Gemini 雲端 API 時使用 | 可選 |

本擴充套件不要求讀取所有網站的權限，也不會將資料傳送到上述以外的伺服器。

## 隱私與使用注意

- 所有設定（包含 API 金鑰與自動登入的 PinCode）**僅存於使用者本機瀏覽器**，本專案不收集任何資料。
- **共用電腦請勿開啟自動登入，也請勿保存 PinCode。**
- 使用雲端 AI 時，公文內容會傳送至該服務商，請依機關規定決定是否使用。
- 送出 AI 前可開啟「遮蔽身分證、手機、Email」選項。
- AI 結果僅供參考，本工具不會自動送出公文，也不會按下「執行」。
